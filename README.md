# forProfZJ

一封给左老师的信（操作系统课）。单文件静态页面，无需构建。

- 信件正文经 PBKDF2 + AES-GCM 加密后内嵌于 `index.html`，源码中不含明文，密码即解密密钥。
- 背景音乐：把音频命名为 `bg.flac`（或 `bg.mp3` / `bg.ogg`）放在本目录即可，播放器按此顺序自动选择可用音源。
- 修改信件内容：编辑 `../letter contexts/forProfZJ/letter-content.html`，然后在该目录运行 `node update-letter.js <密码>`（明文与工具不在本目录，勿将其发布到公开仓库）。

## 设计说明

以"排版考究的技术文档"为基调，冷调靛蓝 + 石墨灰，OS 的意象藏在细节里：

- **页帧矩阵**：启封页的 4×4 方格，验证通过后逐格点亮（页面分配的隐喻），失败则整体轻微抖动。
- **页帧网格背景**：全屏极淡的 64px 网格，边缘用径向遮罩淡出。
- **边界母题**：正文末尾有一道虚线边界，其下的结尾段落与落款左右各探出 26px——呼应"考纲有边界，求知无止境"。该句本身用 `.key-line` 以靛蓝色标出。
- **页边地址**：每段左侧页边有极淡的等宽标记 `0x00`…`0x07`（内存地址的隐喻），编号在那道边界处终止——越界之后的段落不再编址。地址由 JS 在解密注入后按段落顺序自动生成，加减段落无需手工维护；窄屏（<1000px）自动隐藏。
- **引文块**：左老师的两句原话用 `<blockquote class="quote">` 单独成块，左侧一道靛蓝竖线。"多沉淀，少浮躁"用行内 `.stress` 标出。
- **阅读进度**：视口顶部一道 2px 靛蓝细线，随滚动推进。
- **等宽字体**仅用于元信息（日期、提示语、页边地址），不进入正文。
